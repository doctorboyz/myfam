Rule I keep re-learning: for any multi-line Edit in a file read more than a few turns ago, re-read the target range first.

3. **Assumed var() in SVG attributes works**: modern browsers support it, and the deployed bundle confirms it renders the token strings — but I did not actually visually confirm a chart in a browser. A screenshot check would close that loop properly.

## Lessons Learned

- Filters-as-URL-params: a small pure helper (serialize + parse + `range=all` marker for explicit null ranges) is the whole cost of refresh-proof/shareable filters; don't build it into components.
- Uncategorized drill-down reuses the existing `UNCATEGORIZED_FILTER` pseudo-ID — no new API or state needed.
- Recharts colors accept `var(--token)` strings (they flow into SVG presentation attributes); `--chart-*` tokens + one dark override in globals.css theme the entire chart layer.
