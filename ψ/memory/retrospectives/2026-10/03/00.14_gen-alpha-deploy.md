## Lessons Learned

- **Dark-first token systems pay off in small-app redesigns.** Moving everything to a single token layer (`--color-bg`, `--color-surface`, `--color-text`, `--color-primary`, `--color-danger`) made it possible to redesign 8+ screens in four phases without color drift. The few remaining hardcoded hex values were the ones that broke during the build.
- **TMA integration needs a single source of truth for types.** We hit duplicate `Window.Telegram` declarations during earlier phases and fixed it by centralizing types in `src/types/telegram.d.ts`. That prevented similar errors in Phase 4 when more screens started using haptics and the back button.
- **Deploy to local OrbStack is fast but invisible.** Because production is the same machine, it is easy to assume success after `docker-compose up -d`. The smoke test on `/login` is the minimum guard; without it, a silently failing container would go unnoticed.
- **Phase boundaries work well for large UI refactors.** Breaking the redesign into four phases (tokens + dashboard, transactions/accounts/budget, settings/profile polish, motion/haptics/empty states) kept each commit reviewable and each build manageable. The user advanced phase by phase, which matched their decision rhythm.
