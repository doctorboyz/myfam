## Lessons Learned

- **Data fixes need: dry-run default → backup → apply → verify count.** The
  one-time script is the audit record — commit it even when convention says
  one-off scripts stay untracked (see 9bd5f52).
- **When a user reports a missing feature that the code has, check production
  freshness before code paths.** "Is prod running this code?" is the first
  question, not the tenth.
- **Exact-match command buttons must sit above fuzzy regexes** (แก้ยอด vs
  reconcile's /แก้ยอด/) — keyboard texts and fuzzy patterns share one namespace
  in detectCommand.
- **`npm run lint` = bare `eslint`** in this repo: lints scripts/*.cjs and tests
  too — 66 errors currently, ungated because the CI workflow is dead.
