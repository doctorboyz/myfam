## Lessons Learned

1. **Verify through the same path users take.** SQL-level correctness and bot-level correctness are different claims; the bare-keyword gap existed for who knows how long because it only shows in the bot path. The sandbox route is the tool for this — key IS `TELEGRAM_WEBHOOK_SECRET`.
2. **Exact match vs fuzzy for short commands**: when adding a keyword that is a substring of other commands ("ยอด" ⊂ "ปรับยอด", "แก้ยอด"), add it as an exact match (`q ===`), never as a regex alternative — order in the regex alternation won't save you.
3. **Docker volume hygiene on this machine**: `docker volume ls -f dangling=true` is the survey command; volumes here are all named and in-use (myfam, lita-game, magic-numbers, s45, infra-oracle) — `docker image prune -f` + `docker builder prune -f --filter until=48h` is the safe routine (2.32GB back this time).
