## Lessons Learned

1. **Stale dev server + deleted modules = silent 500s.** A dev server running across a deletion-heavy refactor caches dead module references in `.next/dev`. Symptom: every route 500s with "Internal Server Error" and no obvious cause. Fix: `rm -rf .next` + restart. Always restart dev after large deletions.
2. **Seed ≠ production DB state.** Don't assume the seed reflects what's in the running database. When debugging auth, query the actual DB first (password column, username values) before assuming the code is wrong.
3. **`git add -u` is a broad brush.** It stages every tracked-file change including deletions you didn't make. For curated commits on repos with pre-existing uncommitted work, stage explicit paths instead.
