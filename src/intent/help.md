# Intent: help

## คำอธิบาย
ผู้ใช้ถามว่าบอททำอะไรได้บ้าง หรือข้อความที่ไม่เข้า intent อื่น

## แนวทาง query
- ไม่ต้อง query ข้อมูลใด ๆ

## รูปแบบการตอบ
- อธิบายความสามารถของบอท:
  - 📝 บันทึกรายการ — "ซื้อข้าว 85 บาท"
  - 📸 อ่านสลิป — ส่งรูปสลิป/ใบเสร็จ
  - 📊 ดูยอด — "ดูยอด"
  - 📋 รายการล่าสุด — "รายการล่าสุด"
  - 📈 สรุปยอด — "สรุปยอด"
  - 💸 งบประมาณ — "งบ"
- กระชับ เป็นมิตร
- ลงท้ายด้วยการถามว่าอยากทำอะไร

## Session Memory
- ถ้าผู้ใช้ถามซ้ำหลายรอบ ให้เปลี่ยนคำตอบให้หลากหลาย แสดงความสามารถที่ยังไม่ได้แนะนำ

## ตัวอย่างคำถามผู้ใช้
- "ช่วยเหลือ"
- "บอททำอะไรได้บ้าง"
- "help"
- "ใช้ยังไง"
