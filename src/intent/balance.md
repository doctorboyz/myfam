# Intent: balance

## คำอธิบาย
ผู้ใช้ต้องการดูยอดเงินคงเหลือในบัญชี อาจถามแบบกว้าง (ทุกบัญชี) หรือถามเฉพาะบางบัญชี

## แนวทาง query
- `prisma.account.findMany({ where: { ownerId: user.id, status: 'active' } })` — ดึงทุกบัญชีที่ active
- คำนวณยอดรวมทุกบัญชี

## ข้อมูลที่จะได้รับ
```json
{
  "accounts": [{ "name": "ชื่อบัญชี", "balance": ยอดเงิน }],
  "totalBalance": ยอดรวม
}
```

## รูปแบบการตอบ
- แสดงยอดคงเหลือทีละบัญชี ด้วย emoji 💳
- แสดงยอดรวมทุกบัญชีด้วย 💰
- ถ้าผู้ใช้ถามถึงบัญชีที่ไม่มีอยู่จริง ให้บอกว่าไม่พบบัญชีนั้น พร้อมแนะนำให้ตรวจสอบชื่อ
- ถ้าไม่มีบัญชีเลย บอกให้ไปสร้างในแอป
- จบด้วยการชวนถามต่อ

## Session Memory
- ถ้าในประวัติบทสนทนา ผู้ใช้เคยถามถึงบัญชีใดบัญชีหนึ่งมาก่อน และรอบนี้ถามแบบไม่มีชื่อบัญชี (เช่น "แล้วบัญชีนั้นล่ะ") ให้ตอบยอดของบัญชีที่เคยถามถึง
- ใช้ประวัติบทสนทนาในการตีความว่าผู้ใช้หมายถึงบัญชีไหน

## ตัวอย่างคำถามผู้ใช้
- "เหลือเงินเท่าไหร่"
- "ดูยอดหน่อย"
- "บัญชีกรุงไทยเหลือเท่าไหร่"
- "balance"
