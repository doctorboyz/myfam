# Intent: categories

## คำอธิบาย
ผู้ใช้ถามเกี่ยวกับหมวดหมู่รายรับรายจ่าย — มีหมวดอะไรบ้าง, หมวดไหนใช้อะไรได้บ้าง, หมวดไหนใช้เงินเยอะที่สุด, หรือถามเกี่ยวกับแท็ก

## แนวทาง query
- `prisma.categoryGroup.findMany({ include: { categories } })` — กลุ่มหมวดทั้งหมดพร้อมหมวดย่อย
- `prisma.transaction.groupBy({ by: ['categoryId'], _sum: { amount: true } })` — aggregate รายจ่ายตามหมวดในเดือนปัจจุบัน
- `prisma.tag.findMany()` — แท็กทั้งหมดในครอบครัว
- จัด ranking: topGroups (aggregate ตามกลุ่ม), topCategories (เรียงตามยอดใช้จ่าย)

## ข้อมูลที่จะได้รับ
```json
{
  "groups": [
    { "name": "อาหาร", "type": "expense", "subcategories": ["ข้าว", "น้ำ", "ขนม"] }
  ],
  "topGroups": [
    { "groupName": "อาหาร", "amount": 5200 }
  ],
  "topCategories": [
    { "name": "ข้าว", "groupName": "อาหาร", "amount": 3200 }
  ],
  "tags": [
    { "name": "จำเป็น" }
  ]
}
```

## รูปแบบการตอบ
- ถ้าถาม "มีหมวดอะไรบ้าง" → แสดงกลุ่มหมวด แยกตามประเภท (รายรับ/รายจ่าย/โอน) พร้อมจำนวนหมวดย่อย
- ถ้าถาม "หมวด X มีอะไรบ้าง" → แสดงหมวดย่อยในกลุ่มนั้น
- ถ้าถาม "หมวดไหนใช้เงินเยอะสุด" → แสดง ranking top groups เรียงตามยอดใช้จ่าย พร้อมจำนวนเงิน
- ถ้าถาม "ค่ากิน/ค่าอาหารเดือนนี้" → แสดงยอดรวมของกลุ่มนั้น
- ถ้าถามถึงแท็ก → แสดงรายชื่อแท็กที่มี
- ใช้ emoji: 🟢 รายรับ, 🔴 รายจ่าย, 🔄 โอน, 🏷️ แท็ก
- แสดงจำนวนเงินด้วยเครื่องหมายคอมม่าคั่นหลักพัน
- ถ้าไม่มีหมวดหมู่เลย แนะนำให้ไปตั้งค่าในแอป

## Session Memory
- ถ้าผู้ใช้ถาม "แล้วหมวดอาหารล่ะ" หลังจากถามสรุปยอด → รู้ว่ากำลังถามถึง spending ของหมวดอาหาร
- ถ้าถาม "มีหมวดอื่นอีกไหม" → แสดงหมวดที่ยังไม่ได้พูดถึง
- ใช้ประวัติบทสนทนาในการตีความว่าผู้ใช้หมายถึงกลุ่มไหน
