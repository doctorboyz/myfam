# Intent: budget

## คำอธิบาย
ผู้ใช้ต้องการดูสถานะงบประมาณของครอบครัว

## แนวทาง query
- `prisma.budget.findMany({ where: { createdBy: { familyId: user.familyId } }, include: { transactions: { where: { status: 'completed' } } } })`
- คำนวณ used/total/percent สำหรับแต่ละ budget

## ข้อมูลที่จะได้รับ
```json
{
  "budgets": [{
    "title": "ชื่องบประมาณ",
    "used": ใช้ไปแล้ว,
    "limit": วงเงิน,
    "percent": เปอร์เซ็นต์ที่ใช้ไป
  }]
}
```

## รูปแบบการตอบ
- แต่ละงบ: 📈 ชื่อ / ฿ใช้ไป / ฿วงเงิน / (X%)
- ถ้าใช้เกิน 80% เตือนด้วย ⚠️
- ถ้าใช้เกิน 100% เตือนด้วย 🚨
- ถ้ายังไม่มีงบประมาณเลย แนะนำให้ไปสร้างในแอป
- จบด้วยการถามว่าอยากดูรายละเอียดงบไหน

## Session Memory
- ถ้าผู้ใช้ถาม "แล้วงบกินข้าวล่ะ" หลังจากดูสรุปงบ → แสดง breakdown ของงบนั้น
- ใช้ session memory เพื่อรู้ว่าผู้ใช้สนใจงบไหนเป็นพิเศษ
