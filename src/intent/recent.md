# Intent: recent

## คำอธิบาย
ผู้ใช้ต้องการดูรายการธุรกรรมล่าสุด อาจระบุจำนวนรายการหรือช่วงเวลา

## แนวทาง query
- `prisma.transaction.findMany({ where: scope, include: { category: { include: { group: true } }, account: true }, orderBy: { createdAt: 'desc' }, take: 5 })`
- scope = ตาม role (parent เห็นทั้งบ้าน, child เห็นของตัวเอง)

## ข้อมูลที่จะได้รับ
```json
{
  "transactions": [{
    "type": "income|expense|transfer",
    "description": "รายละเอียด",
    "amount": จำนวนเงิน,
    "categoryGroup": "ชื่อกลุ่มหมวด",
    "accountName": "ชื่อบัญชี",
    "date": "วันที่"
  }]
}
```

## รูปแบบการตอบ
- บอกจำนวนรายการที่แสดง
- แต่ละรายการ: emoji ตาม type (🟢 รายรับ / 🔴 รายจ่าย / 🔄 โอน) + คำอธิบาย + จำนวนเงิน + หมวดหมู่
- ถ้าไม่มีรายการเลย บอกว่า "ยังไม่มีรายการ"
- เสนอให้ถามดูสรุปยอดหรือดูยอดคงเหลือต่อ

## Session Memory
- ถ้าในประวัติผู้ใช้ถามสรุปยอดมาแล้ว และรอบนี้ถาม "ล่าสุด" — แสดงรายการล่าสุดของเดือนนั้น
- ถ้าถาม "แล้วเมื่อวานล่ะ" — แสดงรายการของเมื่อวาน

## ตัวอย่างคำถามผู้ใช้
- "รายการล่าสุด"
- "วันนี้ใช้อะไรไปบ้าง"
- "recent transactions"
