# Intent: summary

## คำอธิบาย
ผู้ใช้ต้องการดูสรุปยอดรายรับรายจ่ายในช่วงเวลาหนึ่ง (ค่าเริ่มต้น: เดือนปัจจุบัน)

## แนวทาง query
- `prisma.transaction.aggregate({ where: { ...scope, type: 'income', date: { gte: startOfMonth } }, _sum: { amount: true } })`
- `prisma.transaction.aggregate({ where: { ...scope, type: 'expense', date: { gte: startOfMonth } }, _sum: { amount: true } })`
- ดึง top categories สำหรับรายจ่ายสูงสุด

## ข้อมูลที่จะได้รับ
```json
{
  "monthName": "เดือนภาษาไทย",
  "totalIncome": ยอดรายรับ,
  "totalExpense": ยอดรายจ่าย,
  "balance": รายรับ-รายจ่าย,
  "topCategories": [{ "name": "ชื่อหมวด", "amount": ยอด }]
}
```

## รูปแบบการตอบ
- บอกช่วงเวลา (เดือน/ปี)
- 🟢 รายรับ
- 🔴 รายจ่าย
- 💰 คงเหลือ (รายรับ-รายจ่าย)
- 📂 หมวดที่ใช้จ่ายสูงสุด 3 อันดับแรก
- ถ้าถาม "เดือนที่แล้ว" ให้คิดจากเดือนก่อนหน้า
- จบด้วยการถามว่าอยากดูรายละเอียดหมวดไหน

## Session Memory
- ถ้าผู้ใช้ถาม "เดือนที่แล้วล่ะ" หลังจากดูสรุปเดือนนี้ → query เดือนก่อนหน้า
- ถ้าผู้ใช้ถาม "แล้วหมวดอาหารล่ะ" → รู้ว่ากำลังพูดถึง summary อยู่ → แสดง breakdown ของหมวดนั้น
- ใช้ session memory เพื่อรู้ว่าช่วงเวลาใดถูกถามไปแล้ว

## ตัวอย่างคำถามผู้ใช้
- "สรุปยอด"
- "เดือนนี้ใช้ไปเท่าไหร่"
- "สรุปเดือนที่แล้ว"
- "monthly summary"
